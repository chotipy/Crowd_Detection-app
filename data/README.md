# Data Directory

This directory contains all datasets and data-related artifacts used in the **YOLOv8-based Crowd Detection and Density Classification** project.

The data is divided into two main parts: **raw data** and **processed data**.

---

## Structure Overview

```text
data/
├── raw/
│   ├── frames/
│   ├── mall_gt.mat
│   └── README.md
│
├── processed/
│   ├── images/
│   ├── labels/
│   └── runs/
│       └── yolov8n_mall_person/
│           └── weights/
│               ├── best.pt
│               └── last.pt
```
---

## Raw Data (`data/raw/`)

This folder contains the **original dataset** before any preprocessing or training.

### Contents:
- **`frames/`**  
  Extracted image frames from CCTV footage used as input for annotation and model training.

- **`mall_gt.mat`**  
  Ground truth file containing annotation data (e.g., person counts) for the Mall dataset.

- **`README.md`**  
  Additional description or notes related to the raw dataset.

*Raw data is preserved to maintain reproducibility and allow future reprocessing.*

---

## Processed Data (`data/processed/`)

This folder contains data that has been **processed, annotated, or generated** during training.

### Contents:
- **`images/`**  
  Preprocessed images formatted for YOLOv8 training.

- **`labels/`**  
  YOLO-format annotation files corresponding to each image.

- **`runs/yolov8n_mall_person/`**  
  Training outputs generated by YOLOv8, including logs and model checkpoints.

#### Model Weights:
- **`best.pt`** – Best-performing model based on validation metrics  
- **`last.pt`** – Final model checkpoint from the last training epoch

---

## Notes
- Large files are intentionally organized to keep the repository structured and readable.
- This data structure follows common YOLOv8 training conventions.
- Processed data and model weights are included for transparency and reproducibility of results.

This directory is used by:
